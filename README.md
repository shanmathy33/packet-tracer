# Assignment 1 - Basic LAN Setup

## Objective
To create a basic Local Area Network (LAN) using one switch and four PCs and verify communication between the devices.
## Network Topology and Verification

![Topology and Verification](ass-1-topology-and-verification.png)
## Devices Used
- 1 Switch
- 4 PCs

## Network Topology
Star Topology

## Configuration
- Connected all PCs to the switch using copper straight-through cables.
- Assigned IP addresses to all PCs.
- Verified network connectivity using the ping command.

## Verification
- Successful communication between all PCs.
- Ping test completed successfully.
# Assignment 2 - Single Router Four PC Network

## Objective
To create a network using one router, one switch, and four PCs and verify communication between the devices.

## Devices Used
- 1 Router
- 1 Switch
- 4 PCs

## Network Topology
Star Topology with Router and Switch

## Configuration
- Connected the router to the switch.
- Connected four PCs to the switch using copper straight-through cables.
- Configured IP addresses for all PCs.
- Configured the router interface.
- Verified network connectivity using simulation and ping.

## Verification
- Successful packet transmission between devices.
- Network communication verified in Simulation Mode.

## Software Used
Cisco Packet Tracer
